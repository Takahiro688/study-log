# study-log

毎日の学習時間を記録して、直近14日間の学習状況をマス目でひと目で確認できる Web アプリです。

## できること

- 日付・学習内容・学習時間（分）を記録する
- 直近14日間の学習時間を、色の濃さで表示する（今日のマスは黄色の枠）
- 記録の一覧表示と削除
- 記録はブラウザ（localStorage）に保存されるので、ページを閉じても残る

## 使い方

`index.html` をブラウザで開くだけで動きます。インストールは不要です。

## 使用技術

- HTML / CSS / JavaScript（フレームワーク・ライブラリなし）
- localStorage

学習中の JavaScript の基礎（配列・オブジェクト・DOM操作・イベント）で理解できる範囲に絞っています。

## ファイル構成

```
study-log/
├── index.html        画面の骨組み
├── css/style.css     見た目
├── js/storage.js     データの保存・読み込みだけを担当
├── js/app.js         画面の表示と操作を担当
└── docs/ojt-notes.md AIの使い方OJTのメモ
```

保存処理を `storage.js` に分けているのは、将来保存先をサーバーなどに変えるときに、
画面側のコード（`app.js`）を触らずに済むようにするためです。

## 工夫した点

- **日付のずれ対策**：`toISOString()` は UTC 基準のため、日本時間の早朝に使うと前日の日付になります。年・月・日を自分で組み立てて回避しています。
- **XSS対策**：ユーザーの入力は `innerHTML` ではなく `textContent` で表示しています。
- **入力チェック**：空欄や0分以下、24時間を超える時間は登録できないようにしています。
- **マジックナンバーを避ける**：`14` や `1440` などの数字には名前をつけて、意味がわかるようにしています。
